1. 适用场景

本文适合 Windows 用户从零开始配置 YOLO26 / Ultralytics 环境，主要覆盖：

  • Anaconda3 安装
  • PyCharm 安装
  • CUDA / cuDNN 配置
  • Conda 虚拟环境创建
  • PyTorch GPU / CPU 版本安装
  • Ultralytics 安装
  • YOLO26 权重推理验证

如果你之前已经配置过 YOLO11 / Ultralytics 类似环境，通常不需要重新完整配置，可以直接尝试更新源码和权重文件。

2.1 检查是否有 NVIDIA 独立显卡

深度学习训练对显卡要求较高。建议先打开：

2.2 判断安装 GPU 版还是 CPU 版

电脑情况 推荐安装方式
有 NVIDIA 独立显卡 GPU 版本 PyTorch
无独显 / Intel 核显 / AMD 显卡 CPU 版本 PyTorch

注意：CPU 也可以运行和训练，但速度会慢很多。
