1.1 硬件要求

  • 存储：至少 100 GB 可用空间
  • 系统：Linux（Ubuntu 22.04 推荐）
  • Python：3.10+
  • CUDA：12.x+，NVIDIA 驱动已安装

6️⃣ 常见优化与注意事项

  1. 显存优化：使用 FP8 / GPTQ 量化版本可显著减少显存占用
  2. 网络访问：国内推荐使用 ModelScope 或国内镜像下载模型
  3. 服务稳定性：结合 systemd 或 Docker 容器部署
  4. 多模型部署：若显存允许，可在同一 GPU 上加载多个中型模型
