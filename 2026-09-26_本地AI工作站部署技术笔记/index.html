整理依据：近期 Ubuntu + RTX PRO 6000 本地 AI 工作站部署记录。
当前主要环境：Ubuntu、NVIDIA RTX PRO 6000 Blackwell Workstation Edition 96GB、Tailscale、SGLang、Qwen3.8-27B-NVFP4-NVIDIA、ChatGPT Desktop / Codex、Open WebUI、ComfyUI。
本机 Tailscale 地址示例：100.121.188.86。
安全原则：模型推理端口不直接暴露公网，优先绑定 Tailscale 地址，并用 UFW 再限制公网网卡。
软件版本和命令会持续变化，安装失败时优先核对：Python、CUDA/PyTorch、SGLang、ComfyUI、自定义节点及模型仓库说明。

14. 备注

  • 本文按当前服务器实际部署环境整理，并非所有机器都应照搬相同显存、上下文和 CUDA 参数。
  • 当前服务器 Tailscale 地址示例为 100.121.188.86，如果地址发生变化，应同步更新 SGLang、Open WebUI、ComfyUI 和 Codex Provider 配置。
  • SGLang 0.5.20 是当前实际使用版本记录；以后升级时应重新检查命令行参数。
  • Qwen3.8-27B-NVFP4-NVIDIA 的当前本地路径为 /data_SSD/vLLM/models/Qwen/Qwen3.8-27B-NVFP4-NVIDIA。
  • QWEN3.1 在本次记录中没有找到明确通用模型仓库 ID，因此仅保留通用 Qwen3 部署说明，没有虚构模型名。
  • ChatGPT Desktop / Codex 的 model_catalog_json schema 可能随版本更新，遇到错误时优先对照当前 Codex config schema。
  • Open WebUI 必须保留 /app/backend/data 对应 volume；固定 WEBUI_SECRET_KEY 可避免重建容器后登录和加密数据失效。
  • ComfyUI 的 Save / Save As 与浏览器 Export 不是同一种保存方式。
  • Qwen-Image 2.1 使用 GGUF 主模型时，优先确认 UnetLoaderGGUF，否则即使采样完成也可能输出异常。
  • 模型服务默认不应该暴露公网。优先使用 Tailscale + 服务绑定私网 IP + UFW 三层限制。
